# 六轴机械臂遥控页（BLE / 串口）

单文件网页，打开即用，无需安装。通过蓝牙 BLE 连接 JDY-33 模块控制机械臂，
也支持桌面 Chrome/Edge 的 Web Serial 接 USB 转串口。

## 使用方法

1. 手机/电脑用 **Chrome 或 Edge** 打开本页（iPhone 需用 Bluefy 浏览器）。
2. 点「连接 BLE」，在弹出的设备里选 `JDY-33-BLE`。
3. 连上后拖动滑条、按按钮即可控制；状态栏会实时显示回传的 `$S` 帧。

## 蓝牙参数

| 项目 | 值 |
|---|---|
| 设备名 | `JDY-33-BLE` |
| 服务 UUID | `0000ffe0-0000-1000-8000-00805f9b34fb` |
| 特征 UUID | `0000ffe1-0000-1000-8000-00805f9b34fb` |
| 串口波特率 | 9600 8N1 |

## 串口命令

| 命令 | 作用 |
|---|---|
| `Q` | 查询状态 |
| `HOME` | 全部回零位 |
| `J1,45` | 1 号关节转到 45° |
| `G,1` / `G,0` | 夹爪闭合 / 张开 |
| `S,20` | 速度设为 20% |
| `ESTOP` / `RESUME` | 急停 / 解除急停 |

## 说明

本页是 STM32 六轴机械臂课设的配套上位机界面，源码随项目维护。
